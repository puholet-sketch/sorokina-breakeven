# Точка безубыточности · Сорокина

Публичная управленческая страница по сентябрю 2026 (ИП Сорокина, БЦ 2 этаж).

**Не входит в портфолио** — отдельная ссылка для согласования вводных с точкой.

## Локально

Открыть `index.html` в браузере или:

```bash
npx --yes serve .
```

## Пересчёт данных

Источник цифр: `data/pnl.json`. После обновления JSON:

```bash
python -X utf8 -u _build_js.py
```
